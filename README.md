# 🛒 E-Commerce & Supply Chain Management System

نظام قاعدة بيانات متقدم لإدارة عمليات التجارة الإلكترونية، وتتبع المخزون، والطلب، وتحليل حركة المبيعات للشركات التقنية والريادية.

## 📌 مميزات النظام
- **إدارة العملاء:** تسجيل بيانات المشترين ومدنهم وتاريخ انضمامهم.
- **إدارة المخزون:** مراقبة كميات المنتجات والتنبيه عند انخفاض المخزون لتجنب انقطاع البضائع.
- **تتبع الطلبات:** ربط الطلبات بالعملاء وتحديث حالات الشحن أولاً بأول.
- **تقارير تحليلية:** استخراج إحصائيات مالية وحجم المبيعات باستخدام تجميع البيانات (`GROUP BY`).

## ⚙️ هيكل المشروع
- `database_schema.sql`: بناء الجداول، العلاقات (Foreign Keys)، والقيود (Constraints) والفهارس (Indexes).
- `queries.sql`: يحتوي على بيانات إدخال تجريبية، استعلامات متقدمة، وعمليات التحديث والتعديل.
